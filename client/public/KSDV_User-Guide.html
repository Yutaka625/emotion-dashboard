KSDV · KOKORO SENSOR DATA VISUALIZER

使い方ガイド

心sensorの感情ログ（AFFDEX形式CSV）をブラウザにドロップするだけで、10種類の感情スコアを多角的に可視化・分析できます。このガイドでは基本操作から高度な機能まで解説します。

▶ クイックスタート

初めてお使いの場合は、以下の4ステップで分析を開始できます。

1
CSVファイルをドロップ

心sensorから書き出したAFFDEX形式の.csvファイルを、アップロードエリアにドラッグ＆ドロップ（またはクリックして選択）します。

2
自動解析を待つ

ブラウザ内で統計計算が実行されます（データはサーバーに送信されません）。処理は通常数秒で完了します。

3
「概要」タブを確認

セッション全体のサマリー（記録時間・支配的感情・Engagement平均など）が自動表示されます。

4
左サイドバーでタブを切り替え

「時系列分析」「感情分布」「UXリサーチ」など目的に応じたタブに移動して詳細を確認します。

📂 ファイルのアップロード

基本的なアップロード手順 必須
  1. ブラウザでKSDVを開くと、中央にアップロードエリアが表示されます。
  2. 心sensorから出力したAFFDEX形式の.csvファイルをエリアにドラッグ＆ドロップします。
  3. クリックしてファイルダイアログから選択することもできます。
  4. 「ファイルを読み込み中…」→「データを解析中…」→「統計を計算中…」と進行し、自動でダッシュボードが表示されます。
💡 データはすべてブラウザ内で処理されます。外部サーバーへの送信はありません。
別のファイルを再読み込みするには
  • ダッシュボード右上のファイル名表示エリアをクリックすると、新しいCSVをドロップして解析をリセットできます。
サンプルで試す（ファイルがなくてもOK） お試し

アップロードエリアの下に「サンプルで試す」ボタンが4つあります。クリックすると心sensor準拠のサンプルデータが読み込まれ、そのまま解析画面に進みます。各機能の動作確認にご利用ください。

ボタン内容
基本サンプル実データ（単一セッション・約2分）。概要〜各タブの動作確認用
A/B比較デモ2つの実セッション（別時刻の記録）を読み込み、比較タブ（統計検定含む）へ遷移
ベースライン・変化点実データ（単一セッション）。ベースライン補正・変化点検出の確認用
マルチFaceID複数の顔を含むデータ（顔ごとの比較・ノイズ除外の確認用）
📄 アップロード画面の下部には「利用規約・プライバシーポリシー」へのリンクもあります（新規タブで開きます）。

🔍 タイムレンジ指定

「時系列分析」タブ内の TIME RANGE FILTER で、分析対象の時間範囲を0.1秒単位で絞り込めます。

操作手順
  1. 左サイドバーから「時系列分析」タブを開きます。
  2. TIME RANGE FILTER セクションで「開始秒」「終了秒」を入力します。
  3. プリセットボタン（全体 / 0-60s / 60-120s …）で素早く切り替えることもできます。
  4. 指定後、グラフとすべての統計が選択範囲のデータに絞られます。
  5. 「CSV出力」ボタンを押すと、出力設定の画面が開きます。条件を変えずに「そのまま出力」を押すと、元データの全列を加工せず emotion_data_○-○s.csv としてダウンロードできます。
  6. 出力設定の画面では、必要に応じて次の条件を選べます：FaceID（人物）の範囲（複数人データのとき：選択中の顔のみ／全員をまとめて／FaceIDごとに分割〔1ファイルに FaceID 列を付与〕）／時間範囲／time列の表記（元の値そのまま〔加工なし。後から検知が始まった人物の開始時刻も保持〕／0秒始まりに揃える）／出力する列（既定で全列。グループ単位で不要分のチェックを外せる：感情〔ニュートラル含む〕・特殊指標・Action Units・ヘッドポーズ・その他の計測値〔輝度・瞳孔間距離・バウンディングボックス・ランドマーク座標など〕）／数値の精度・データ量（小数桁数・全フレームの生データ／最大600点に間引き）。
💡 ベースライン補正と組み合わせる場合は、先にタイムレンジを安静時区間に合わせて「ベースラインとして設定」を押します。
📊 研究で使う場合：感情・表情などの値は元データそのまま（加工は小数桁の丸めのみ）。timeの原点（元の値／0秒始まり）は平均・相関・検定などの値ベース統計には影響しません。複数人の時間整列を保ちたいときは「元の値そのまま」または「0秒始まり（全体基準）」を、刺激提示などへの時間ロックは出力後にご自身のイベント記録で整列してください。

📌 イベント登録

タスクや刺激の区間に名前と時間帯を登録すると、グラフ上に色付き縦線が表示され、区間ごとの感情統計が自動生成されます。

イベントを追加する
  1. 「時系列分析」タブ内の EVENT ANNOTATIONS セクションを開きます。
  2. 「＋イベント追加」ボタンをクリックしてフォームを表示します。
  3. イベント名（例：「タスクA」「広告視聴」）・開始秒・終了秒を入力して「追加」をクリックします。
  4. グラフに色付き縦線が引かれ、その区間の感情統計（EVENT EMOTION STATS）が表示されます。
  5. 複数イベントを登録して区間間の反応を比較できます。
💡 登録したイベントは「UXリサーチ」タブの「タスク別サマリー」にも自動連携されます。
区間間の統計比較（t検定）
  • 複数イベントを登録したあと、「区間を比較」機能で2つの区間を選ぶと、各感情スコアのt検定結果（p値・有意差フラグ）が自動表示されます。

⚖️ ベースライン補正

刺激なしの安静時区間を「ベースライン」として登録することで、感情スコアを安静時との相対値で見られるようになります。被験者間比較や研究レポート作成に有効です。

ベースライン区間を設定する 推奨手順
  1. 「時系列分析」タブで BASELINE SETTINGS カードを開きます。
  2. 開始秒・終了秒を手動入力するか、「自動検出」ボタンで最も感情変動が少ない30秒区間を自動特定します。
  3. 「ベースラインとして設定」を押すと、区間ごとの平均/中央値が計算されます。
  4. 画面上部のグローバルバナーに表示モード切替ボタンが現れます。目的に合わせてモードを選択します（下表参照）。
💡 中心統計量は 平均（mean） と 中央値（median） から選べます。外れ値が多いデータには中央値が安定します。
4つの表示モード
モード計算式向いている用途
absolute 補正なし（生スコア） 一般閲覧・ベースライン設定前の確認
deviation スコア − ベースライン平均 before/after比較・研究発表スライド
lift (スコア − ベースライン) ÷ ベースライン × 100% 変化率での被験者間比較
zscore 研究者向け (スコア − ベースライン平均) ÷ SD 論文・統計的有意性の検討
⚠️ deviation / lift / zscore モードではスコアがマイナスになる場合があります（安静時より感情が低下した状態を意味します）。
補正を解除するには
  • 画面上部のグローバルバナーで 「absolute」 を選択、またはバナー右端の「解除」ボタンをクリックすると元のスコアに戻ります。

〜 スムージング（ノイズ除去）

フレーム単位のノイズを平滑化して、感情の大きなトレンドを見やすくする機能です。「時系列分析」タブの SMOOTHING SETTINGS カードで設定します。

3つのスムージングモード
モード特徴設定パラメータ
none 平滑化なし。生の計測値をそのまま表示 —
SMA（単純移動平均） 直近Nフレームの平均値を表示。ノイズを均等に除去 ウィンドウサイズ 5〜60 フレーム
EMA（指数移動平均） 直近フレームを重視しつつ平滑化。変化への追従が速い alpha 0.01〜0.5（大きいほど追従速度が上がる）
💡 スムージングはグラフ表示のみに影響します。統計カード（平均・SD・中央値など）は常に生データから計算されます。
💡 有効にすると画面上部のグローバルバナーにスムージングバッジが表示されます。
使い分けの目安
  • プレゼン・スクリーンショット用：SMA ウィンドウ 15〜30 フレームが見やすい
  • リアルタイム性を重視：EMA alpha 0.3〜0.5 で急変を追いながら平滑化
  • 学術分析・統計検定：none（生データのまま）を推奨

👥 FaceID別データ表示

複数の被験者データが1つのCSVに含まれている場合（FaceID列あり）、自動で人物ごとに分離して切り替えられます。

FaceID切り替えUI
  • 複数FaceIDが検出されると、ダッシュボード上部にFaceIDセレクターが表示されます（各FaceIDは識別色付き）。
  • 「全員」ボタン：すべての被験者を合算したデータを表示します。
  • 個別チップ（FaceID名／ラベル名）：クリックするとその1人のデータに切り替わります。
  • Ctrl/Cmd＋クリック：複数人を選択して合算表示できます。
💡 FaceID列がない、または1人分のデータのみの場合は通常モードで動作し、このUIは表示されません。
ノイズ（少フレームFaceID）の自動除外 データ品質

心sensorでは、検出が不安定だと同一人物が別IDで採番されたり、数フレームだけの誤検出IDが生じることがあります。KSDVはこうした少フレームのFaceIDを自動で「ノイズ」と判定し、既定で解析対象から除外します。

  • 既定の判定基準：出現フレーム数が「総フレームの5%未満」または「約3秒未満」のFaceID（しきい値は変更可能）。
  • 除外があると上部に品質バナー（例：「FaceID 4個検出 / 1個をノイズ除外」）が表示されます。
  • 除外により「全員」合算の集計品質も向上します（ノイズのフレームを混ぜずに集計）。
🔧 しきい値の調整・除外内訳の確認・「微小なIDも表示」での再表示・FaceIDへのラベル名付けは、サイドバーの「マルチFaceID」タブで行えます。ラベル名はブラウザに保存され、同じファイルを再度開くと復元されます。

🆚 CSV比較（A/B分析）

2つの異なるセッションのCSVを読み込んで並列比較できます。A/Bテスト・条件比較・before/afterの検証に使います。

比較CSVを追加する
  1. メインCSVを読み込んでダッシュボードを表示します。
  2. ヘッダー右上の「＋比較CSV」ボタンをクリックします。
  3. 比較用のCSVファイルを選択します。
  4. 自動で「比較分析」タブに切り替わり、2セッションの並列比較が表示されます。
💡 比較データを削除するには「比較中: ○○」ボタン右の × をクリックします。
💡 比較CSVを追加すると、ヘッダーに 「表示中 A / B」切替トグルが現れます。「比較分析」タブ以外（概要・感情分布・特殊指標など各タブ）に表示するセッションをA／Bで切り替えられます。「比較分析」タブは切替に関係なく常に A 対 B を表示します。
💡 「セッション情報」は表示中のA/Bに連動します。Aを表示中に開くとSession Aの被験者属性・実験条件・測定環境を編集し、Bを表示中に開くとSession Bの情報を編集します。入力内容はファイル名をキーにブラウザへ保存され、A/Bそれぞれ別のセッション情報として扱われます。

⊞ タブ①：概要（Overview）

CSVを読み込んだ直後に表示される全体サマリーです。セッションの「顔」を確認するのに使います。

総フレーム数 記録時間 平均Engagement 平均Attention 支配的感情 感情多様性 感情分布ドーナツチャート 感情プロファイル（レーダー） KEY INSIGHTS（自動コメント） DATA QUALITY（顔検出率・fps）

支配的感情はそのフレームで最もスコアが高かった感情です。ドーナツチャートで全体に占める割合が確認できます。

KEY INSIGHTS はルールベースのインサイトエンジンが重要度スコアで順位付けし、上位4件を自動表示します。各インサイントには positive / neutral / caution / alert のトーンバッジが付与され、セッションの状態を一目で把握できます。

⚡ タブ③：特殊指標（Engagement / Valence）

Engagement（関与度）とValence（感情価）をタブで切り替えながら深掘り分析するセクションです。

Engagement タブ
  • 基本統計量：平均・最大・中央値・標準偏差の4カード
  • レベル分布：5段階（Very Low〜Very High）のフレーム数分布
  • 感情との相関係数：Engagementと各感情のPearson相関を横棒グラフで表示。+1.0に近いほど同時に高くなる傾向
  • Engagement × Valence 散布図：各フレームを2次元空間にプロット。右上＝積極的かつポジティブ
  • 感情プロファイル比較：Engagement高時 vs 低時の感情スコア比較棒グラフ
  • Affect Dynamics：変動性(SD)・不安定性(MSSD)・慣性(AR1)・レンジ・平均絶対変化量
Valence タブ
  • Valenceの基本統計量・レベル分布・感情との相関係数
  • Affect Dynamics（Valence版）
  • ※ Circumplex Model（円環モデル・4象限分析）は「学術的分析」タブに集約しています。

📊 タブ④：感情分布（Emotions）

10種類の感情スコアの統計的分布と出現パターンを横断的に分析します。

感情カード × 10枚（平均・最大・支配率） 感情出現率（Prevalence） 記述統計表（全感情×平均・SD・最大・中央値） Affect Dynamics 比較棒グラフ（変動性・不安定性）

感情出現率は「その感情が有意に出現した時間の割合」で、平均スコアとは異なる指標です。閾値はスコア 0.3（0〜100スケール）で、低めに設定されているためわずかな表出も出現として数えます。例：喜び 68% → セッションの68%の時間で喜びスコアが 0.3 以上だった。

記述統計表には各感情の n（有効フレーム数） 列があります。これは統計の計算に使われた「欠損を除いた実際のフレーム数」で、検定や平均値の信頼性を判断する材料になります（n が極端に少ない感情は値が不安定）。あわせて 平均±SD のエラーバー付き棒グラフで、ばらつき（標準偏差）も確認できます。

B. Affect Dynamics（感情動態指標）の解釈目安

AR1（慣性）は感情状態の「持続しやすさ」を示します（−1〜+1）。

AR1の範囲解釈
0.85 以上感情状態が硬直しやすい。一度変わると長く持続する傾向
0.50〜0.85中程度の持続性
0.30〜0.50普通の変化しやすさ
0.30 未満感情が移ろいやすい・反応的（刺激に素早く反応して変化）
負値振動パターン（↑↓↑↓と交互に変化する）

MSSD と SD² の比較（不安定性の解釈）：

比較解釈
MSSD ≈ SD²変化がランダムウォーク的（規則性のない揺れ）
MSSD > SD²急激な変化が頻発（突発的な感情変化が多い）
MSSD < SD²変化が緩やか（感情が滑らかに推移）
📚 参考文献: Kuppens et al. (2010). Emotional inertia and psychological maladjustment. Psychological Science, 21(7), 984–991.
C. ベースライン補正の方法論的記載
モード使う場面値域
deviation（偏差）標準的な実験研究。方向性（正/負）を保持負値あり
lift（変化率%）「ベースラインから何%増減したか」を比較±%
zscore個人間の標準化が必要な場合。SD < 0.05 は「—」表示SD単位
⚠️ liftモードはValenceで常に「—」表示されます（符号付き指標のため変化率計算が成立しない）。Valenceにはdeviatioまたはzscoreを使用してください。

論文Methods記述例（deviationモード）：

測定開始前30秒間（t = 0〜30 s）を安静時ベースライン区間として設定し、各感情スコアおよびEngagement・Valence・Attentionからベースライン平均値を減算した（deviation mode）。ベースライン中心値には算術平均を使用した（Kuppens et al., 2010）。
D. 統計検定の選択指針と多重比較の注意
状況推奨検定
標本が大きく（各群 n ≥ 30）、分布が概ね正規的Welch t検定
外れ値が多い・正規性が疑わしい・標本が小さいMann-Whitney U検定

⚠️ 多重比較補正（重要）： KSDVは9感情を補正なしで独立検定します。論文発表時は研究者自身で補正を適用してください。

補正方法特徴9感情の場合の修正後有意水準
Bonferroni補正保守的。確実に第1種過誤を抑制α' = 0.05 / 9 ≈ 0.0056
Holm法Bonferroniより検出力が高い各p値を小さい順に調整
FDR補正（Benjamini-Hochberg法）探索的研究向け。偽陽性率を制御推奨FDR < 0.05

論文Methods記述例：

各感情スコアのセッション間差はWelch's t検定（両側）で検定し、多重比較に対してBonferroni補正を適用した（α' = .05/9 = .006）。効果量はCohen's dで評価した（小: d ≥ .2, 中: d ≥ .5, 大: d ≥ .8; Cohen, 1988）。正規性が確認できない場合はMann-Whitney U検定（効果量: rank-biserial r, 小: r ≥ .1, 中: r ≥ .3, 大: r ≥ .5）を代替的に用いた。
E. 査読で問われやすい論点と回答指針
問い回答指針
変化点検出の 2.5σ 閾値の根拠は？信号処理・異常検知の標準値（グローバルSDの2.5倍）。現バージョンは固定値。論文では「探索的な検出」として記述し、感度分析（2.0σ / 3.0σでの比較）を補足することを推奨。
Engagement を覚醒度（Arousal）代理指標として使う根拠は？Affectiva社のモデル定義に準拠。ただしAffectivaの覚醒度とRussell (1980) の理論的Arousalは完全に等価ではないため、論文中での言及を推奨。
UX スコアの重みの根拠は？当システム固有の経験的設計値（例: confusion×0.4 + anger×0.3 + …）。論文では「参考指標・探索的分析」として位置づけ、感情スコアの生値と並記することを推奨。
Circumplex モデルはベースライン補正の影響を受けるか？受けない。絶対値スケールを前提とした計算のため補正対象外。補正有効中は「補正対象外（絶対値）」バッジが表示される。
多重比較補正はアプリに実装されているか？実装されていない（上記セクションDを参照）。
感情スコアの信頼性・妥当性の根拠は？Affectiva（現iMotions）の計測エンジンの精度に依存。論文にはAffectiva社の検証資料・先行研究を引用し、使用モデルのバージョンを明記すること。
データの正規性はどう確認するか？感情スコアは一般に右歪み（低スコア側に値が集中）。記述統計表でmean >> medianなら歪みを疑い、Mann-Whitney U検定を採用すること。
F. 結果の論文記載例（テンプレート）

感情統計の記述例：
